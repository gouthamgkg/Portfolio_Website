## 🌟 Overview

A modern, high-performance portfolio website engineered with **Material Design 3**, **Glassmorphism**, interactive **WebGL 3D graphics**, and fluid motion physics. Built from the ground up using **Vanilla HTML5, CSS3, and JavaScript** with zero heavy framework bloat.

Showcasing **4+ years of professional engineering expertise** delivering robust enterprise platforms, high-security **NBFC & Chitty FinTech core engines**, and scalable **HRMS & ERP platforms**.

---

## 🚀 Key Features & Visual Design

- 🖥️ **IDE Glass Window Hero Workstation**:
  - Features an animated developer workstation housed inside a sleek macOS/Material IDE glass window frame.
  - Complete with colored control dots (`#ef4444`, `#f59e0b`, `#10b981`), terminal title `goutham_workspace.live`, live status pulse pill, and dynamic role typewriter effect.

- 🌌 **Interactive 3D WebGL Background**:
  - Built with **Three.js** rendering a dynamic particle constellation and geometric depth field responding in real time to mouse parallax.

- 📐 **Vector SVG Project Architecture**:
  - Bespoke, tailored flat-vector illustrations with inline CSS animations for each featured enterprise system:
    - **FinTech & NBFC Suite**: Banking vault, EMV chip card, and financial ledger analytics.
    - **HRMS & Inventory ERP**: Organizational hierarchy tree and warehouse storage scan beam.
    - **Work Management & Ticketing**: Clean 3-column Kanban sprint board (`TO DO`, `ACTIVE`, `RESOLVED`) and SLA timer.
    - **Third-Party API & Automation Suite**: Central REST API gateway, SQL sync, and worker routine nodes.

- 📊 **Animated Live Stat Counters**:
  - IntersectionObserver-powered metrics with horizontal number-and-suffix grouping (`4 +`, `10 +`, `15 +`, `100 %`).

- 🗂️ **Material 3 Segmented Filter Tabs**:
  - Instant client-side project filtering with animated active pill indicator and smooth transitions.

- 🎨 **Persistent Dark / Light Theme System**:
  - Curated HSL color palette with smooth CSS variable transitions, saved across sessions via `localStorage`.

- 📱 **Fully Responsive & Accessible**:
  - Fluid typography via `clamp()`, mobile slide-out navigation drawer with touch backdrop, custom spring-physics cursor follower on desktop, and accessible ARIA attributes.

## 💻 Running Locally

No npm build steps or complex dependencies required. You can serve the project using any local HTTP server:

### Option 1: VS Code Live Server
1. Open the project folder in **VS Code**.
2. Right-click `index.html` and click **"Open with Live Server"**.

### Option 2: Python HTTP Server
```bash
# In the project root directory:
python -m http.server 8080
```
Then visit `http://localhost:8080` in your web browser.

### Option 3: Node.js `npx serve`
```bash
npx serve .
```
